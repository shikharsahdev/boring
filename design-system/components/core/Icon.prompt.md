Renders one Lucide glyph at any size, inheriting text colour. Intentional addition — Boring has no drawn icon set of its own yet, so Lucide is a flagged substitution.

```jsx
<Icon name="calendar-check" size={22} />
<Icon name="heart-pulse" size={40} color="var(--accent)" />
```

Sizes: 18 inline with text, 20–22 in controls, 28–40 as a quiet section mark. Never use emoji in place of an icon.
