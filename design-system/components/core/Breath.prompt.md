Use Little b, the approved butter-coloured character, for identity and calm waiting states.

```jsx
<LittleB size={34} />
<LittleB size={88} state="waiting" />
```

Import `LittleB` from `Breath.jsx`. `Breath` remains an API alias for existing consumers and now renders Little b. Load `styles.css` for the token-driven settle and blink animations. Respect reduced motion. Put a descriptive loading status beside the mark and stop animation when work completes. Default colours are butter and ink; use at least 24 px width.
